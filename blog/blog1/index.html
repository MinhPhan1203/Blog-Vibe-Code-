Hello, welcome to my first blog!

I'm excited to share with you how i got started with coding and web development.

First, i will talk about my journey into coding. And you can read if you want to study more about it i mean for the web development and your skills. There are my experience and you can learn or read for fun. Now let's get started!

I started learning to code because I was fascinated by the idea of creating things that could be used by others or learn about it. I have some small projects under my belt now. You can check them from my github profile or dms my on discord i will share you it.

Next you can learn code on many website like W3Schools , MDN Web Docs and freeCodeCamp . If you a Vietnamese or know about Vietnamese you can learn in F8 FullStack . You don't know how to start learning from scratch you can read it in Roadmap . This website teaches you from zero to hero with a clear study plan. You can start with a small project like profile card for you or a simple website. Last but not least, don't forget about the command line when you're coding.

Towards the end, when you can read the code and understand it or logic you will be able to build more complex applications. Learn more about web technologies like Bootstrap , Vue.js , and React . Database like MongoDB , PostgreSQL and MySQL .

Finally, remember that practice is key to improving your coding skills. Don't be afraid to make mistakes and learn from them. Good luck!
